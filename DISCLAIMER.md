# Disclaimer

This is an unofficial community guide. It includes reviewable source and local build scripts for an experimental bridge reference, but no prebuilt executable, installer package, credentials, or live connection material. Use it only on systems and accounts you own or are authorized to administer.

It describes SSH remote-project access for Codex. It does not grant remote-desktop access, bypass Windows sign-in or access controls, or authorize access to third-party systems.

Always review your network policy, SSH configuration, user permissions, and organizational requirements before deployment.
